# 🫀 LifeSpan 健康預測

## 個人健康管理與延壽系統

輸入健康數據 → 預測生理年齡與預期壽命 → 慢性病風險分級 → 主動預警與個人化延壽建議。

**線上使用：** 開啟 `index.html`，或部署至 GitHub Pages（`https://cyysongyy.github.io/health/`）。

> ⚠️ **免責聲明：** 本系統為健康自我管理與衛教用途，所有預測皆為基於公開流行病學研究的統計估算，**不能取代醫療診斷**。如有健康疑慮，請諮詢合格醫師。危急症狀請立即就醫。

> 本系統與「補救教學系統」為兩個完全獨立的專案，彼此無關、不共用資料。

## 🚀 快速上手（3 步）

1. **匯入你的健保資料**（最重要）
   到「健保快易通 App」或[健康存摺網站](https://myhealthbank.nhi.gov.tw/)登入 → 下載自己的資料（JSON）→ 回到本 App「🔗 匯入串接」上傳。系統會自動整理出 **檢驗、用藥、手術、影像、就醫診斷（病史）、篩檢（如糞便潛血）**，並在匯入後以膠囊標籤顯示「本次新增各幾筆」。
   > 💡 每次有新資料就重新匯入一次即可（健保為完整快照，會自動汰換舊的、以原始採檢日重建，不會重複）。

2. **看分析**
   到「🧠 綜合分析 → 本機綜合分析」，**不需任何金鑰**即可看到：健康分與風險、🔮 健康走向預測、💊 用藥依從性、🩺 照護缺口（該驗未驗）、🩺 就醫診斷病史。想要 AI 白話解讀與問答，再到「設定」填自己的 Gemini／OpenAI 金鑰（選填）。

3. **備份**
   到「⚙️ 設定 → 💾 備份與還原」按「💾 立即備份」（存到你自己的雲端硬碟）或「🔒 加密備份」（設密碼）。**換手機／清快取都不怕丟。**

> 🔐 **你的資料只存在你自己的裝置**（與你自己的雲端／自己的 AI 金鑰）。本 App 沒有伺服器、開發者收不到你的資料。

## ✨ 功能特色

| 功能 | 說明 |
|---|---|
| 📊 綜合健康評分 | 整合心血管、身體組成、活動、飲食、睡眠、菸酒、心理、代謝 8 大面向加權 |
| ⏳ 生理年齡預測 | 依生活型態估算「身體年齡」與實際年齡的落差 |
| 🕰️ 預期壽命推估 | 基於實證因子估算壽命區間與「可再爭取的年數」 |
| 🔬 風險預測 | 心血管疾病、第二型糖尿病（FINDRISC 風格）、代謝症候群 相對風險分級 + 雷達圖 |
| 🚨 智慧預警 | 主動警示（門檻＋惡化趨勢）、未來走向預測（何時跨越危險門檻）、最佳方案模擬器 |
| 🔮 健康走向預測 | 免金鑰：以歷次檢驗做直線推估「照目前速度多久會跨過風險門檻」（如 eGFR 約 2 年後跌破 60、HbA1c 約 1 年後超過 6.4）；改善中的項目給正向回饋 |
| 💊 用藥依從性（PDC） | 免金鑰、健保獨有：用「領藥日期＋給藥天數」估算慢性病藥物近一年的**服藥涵蓋率**（≥80% 視為規律）與中斷段數；涵蓋率偏低又逢對應檢驗惡化時提示「規律服藥可能有助改善」 |
| 🩺 照護缺口提醒 | 免金鑰：由檢驗＋用藥＋**健保確診（ICD）**推斷慢性病與族群，對照指引間隔標出「從未檢驗／逾期未驗」（如糖尿病該驗 HbA1c／腎功能／尿蛋白），並列出建議篩檢（大腸癌、乳癌、子宮頸、糖尿病眼底…） |
| 🩺 就醫診斷（病史） | 從健保就醫紀錄擷取 **ICD 診斷**（如 I10 高血壓、E11 糖尿病），整理成可瀏覽增修的病史清單；並作為慢性病「地面真相」，讓照護缺口與風險判斷更準 |
| 🔎 篩檢紀錄 | 擷取健保檢驗區的**質性結果**（如糞便潛血 FOBT 陰／陽性），讓「大腸癌篩檢」照護缺口改為證據導向：近 2 年已做→✅、逾期→建議再篩、陽性→⚠️ 建議大腸鏡 |
| 📷 檢驗報告辨識 | 選填：拍照／上傳健檢報告（圖片或 PDF，PDF 自動逐頁轉圖，Gemini／OpenAI 皆可）或**貼上純文字**，AI 辨識數值；登入雲端可留底原檔備查 |
| 🧪 檢驗數據庫 | 辨識／匯入的檢驗值依時間與類別統一彙整，涵蓋 **50+ 常見健檢／健保項目**（血壓、血糖、HbA1c、血脂、腎功能 eGFR/Cr/BUN/尿酸、電解質 Na/K/Cl/Ca/P/Mg、肝膽 GOT/GPT/γ-GT/ALP/膽紅素/蛋白、全血球計數含五分類 differential、甲狀腺 TSH/FT4/T4/T3、發炎 CRP、腫瘤標記 AFP/CEA/PSA…），以資料表驅動的參考範圍分級；清單外項目歸入備註）：總覽摘要、**異常警示（正常／注意／過高 ⚠️／嚴重 🚨 分級標色、警示橫幅、可選聲音提醒）**、總體分析（首次→最新變化、改善／惡化趨勢、範圍／平均）、單筆檢視、單項時序趨勢圖、全部紀錄表、單筆新增／編輯／刪除、CSV 匯出、雲端同步 |
| 💊 用藥紀錄 | 從健保「健康存摺」自動解析用藥：支援 **FHIR**（MedicationRequest／Dispense／Statement，含 `medicationReference`）＋健保「**醫療類**」JSON（官方 `myhealthbank.bdata` 格式，`rN.M` 欄位；用藥在門診／住院／牙科等就醫紀錄的巢狀明細，以藥品代碼／名稱／日數樣態辨識，日期取自該次就醫）＋一般代碼／中文欄位格式，含**民國年日期**（1140310→2025-03-10）。彙整成用藥清單：依日期排序、近 90 天用藥摘要與多重用藥提醒、單筆新增／編輯／刪除、CSV 匯出、雲端同步 |
| 🔧 手術紀錄 | 從健保「健康存摺」醫療類 `bdata` 自動擷取住院／門診中的**手術與處置**（以「術／切除／修補／置換／內視鏡…」等關鍵字辨識，帶出日期、相關診斷與院所），彙整成手術史資料庫：總覽、單筆新增／編輯／刪除、CSV 匯出、雲端同步，並納入綜合報告與 AI 綜合解讀 |
| 🩻 影像病理報告 | 從健保「健康存摺」醫療類 `bdata` 擷取超音波／X 光／CT／MRI／內視鏡／病理等**影像與病理報告**（多為英文敘述），彙整成資料庫，並可**一鍵 AI 翻譯成中文**（含白話摘要）；單筆新增／編輯／刪除、CSV 匯出、雲端同步，並納入綜合報告與 AI 綜合解讀 |
| 🧭 交叉分析與預警 | 跨資料交叉比對（影像病理 × 用藥 × 檢驗）找出早期警訊：**影像／病理報告紅旗掃描**（nodule／mass／結節／腫瘤／結石…關鍵字提示追蹤）、**照護缺口**（長期服降血糖／降血脂／降血壓藥卻久未追蹤對應檢驗）、**慢性用藥×腎功能**追蹤提醒；每項附「🔗 依據」與「💡 建議」，並併入每日健康警戒彈窗與 AI 綜合解讀 |
| 🔔 健康警戒系統 | 綜合檢驗、用藥、風險與趨勢自動把關，偵測到**危急值／多項偏高／惡化趨勢／風險極高／用藥控制未達標（如服降血脂藥但 LDL 仍偏高）／多重用藥／太久未追蹤**時，以**彈出視窗**提醒並附「💡 解決之道」；可設定**每天開啟自動檢查**（每天最多一次），或隨時手動「立即健康檢查」 |
| 🔗 資料串接 | 健康存摺 FHIR/JSON（擴充 50+ 項 LOINC 對應、依原始檢驗日期建立多筆紀錄並自動併入檢驗數據庫；**用藥紀錄一併解析**）、Apple 健康 / Google Fit、App JSON/CSV 匯入自動帶入；支援 .zip／.gz 壓縮檔自動解壓與多檔合併，含**密碼保護的 ZIP／PDF**（會提示輸入密碼） |
| 📈 趨勢追蹤 | 儲存紀錄點，追蹤體重、血壓、血糖、健康分、生理年齡變化 |
| ✅ 每日習慣 | 喝水、運動、蔬果、睡眠等每日打卡與連續天數 |
| 💡 延壽行動清單 | 依影響程度排序的個人化建議（附預估延壽年數） |
| 📋 綜合報告 | 整合健康評估、檢驗數據庫、風險、習慣與趨勢，交叉分析（代謝症候群群集、血脂×心血管、腎功能×血壓等關聯）產出重點、優先行動與可選 AI 綜合解讀 |
| 🔄 自動連動 | 檢驗值變動（辨識／新增／編輯／刪除）時，自動把最新生物指標帶入健康評估並重算健康分／風險／報告，儀表板即時更新，無需手動再產生預測 |

## 📲 安裝成手機 App（離線可用）

本系統為 **PWA（漸進式網頁應用）**，可安裝到手機主畫面，安裝後即使**沒有網路**也能開啟使用本機功能：

- **Android／Chrome：** 開啟網站 → 右上選單 →「安裝應用程式／加到主畫面」，或到「設定 → 📲 安裝 App」按「安裝到主畫面」。
- **iPhone／Safari：** 開啟網站 → 分享鈕 ⬆️ →「加入主畫面」。

安裝後 Service Worker 會快取主程式與相依資源（Chart.js、Firebase、pdf.js、字型等），離線時：

- ✅ 可用：健康評估、檢驗數據庫與分析、足部復健、趨勢圖、每日習慣、綜合報告（本機資料）
- 🔌 需連線：Firebase 雲端同步、AI 檢驗辨識與 AI 健康顧問

> 首次請在**有網路**時開啟一次以完成快取；之後離線即可使用。改版時只要重新整理即會自動更新快取。

## 🦶 足部訓練（主程式分頁）

在主程式導覽列的 **🦶 足部訓練** 分頁中，包含兩塊：

| 區塊 | 內容 |
|---|---|
| 📷 垂足外觀 AI 評估 | 拍 1～4 張照片，AI 從外觀綜合病史給觀察與建議（輔助參考，非診斷；需 AI 金鑰） |
| 🏋️ 復健訓練系統 Rehab R5 | 內嵌 [Rehab R5-AI-PRO](https://cyysongyy.github.io/rehab/) 復健系統：訓練計時、每日回報（疼痛／血壓）與統計圖表 |

- **內嵌方式**：復健系統以 `<iframe>` 沙箱化嵌入（`sandbox` 不含 `allow-top-navigation`，避免其 `base target=_top` 劫持主程式），並**延遲載入**——僅在開啟本分頁時才連網，維持本機優先。
- **走路資料回傳（🚶 走路訓練紀錄）**：因兩者同源（皆 `cyysongyy.github.io`），復健系統每次走路存檔會把 `{步數, 公里, 分鐘}` 透過 `postMessage` ＋共用 `localStorage`（`lifespan_walk_log`）回傳，主程式收進 `state.walks[]`，計算今日／近 7 天里程、連續天數並可匯出 CSV；復健系統「每日回報」的血壓／心率則併入檢驗數據庫（餵入趨勢與風險引擎），疼痛／精力存入 `state.checkins[]` 供 AI 顧問參考。
- **需連網**：復健系統載入 Chart.js 等資源，需要網路；也可點「在新分頁全螢幕開啟 ↗」單獨使用。

> ⚠️ 本分頁為衛教與自主訓練用途，不能取代醫療診斷。若疼痛加劇、麻木或不適，請諮詢復健科或物理治療師。

## 🔗 資料串接（匯入）

系統可自動解析並帶入外部健康資料，全程在瀏覽器端完成、資料不外傳：

| 來源 | 檔案格式 | 自動擷取 |
|---|---|---|
| 🏥 健康存摺（My Health Bank） | FHIR Bundle / JSON | 血壓、血糖、糖化血色素、總膽固醇、HDL、體重、身高、心率（依 LOINC 代碼） |
| ⌚ 穿戴裝置 | Apple 健康 `export.zip`／`export.xml`（可直接上傳整包 zip）/ Google Fit JSON | 每日步數→每週運動量、靜止心率、睡眠時數；並依**原始日期**建立體重／血壓／血糖／靜止心率的歷史紀錄，直接進趨勢分析 |
| 📲 iPhone 健康主動同步 | iOS「捷徑」→ `#hs=` 網址參數或剪貼簿 | 當日 體重／血壓／心率／血糖 一鍵或**每天自動**同步為帶日期檢驗紀錄 |
| 📎 現有 App / 附件 | JSON / CSV | 依欄位名（含中英文）自動對應 |

> **關於 iPhone 健康：** 網頁／PWA 無法直接讀取 Apple 健康（HealthKit 僅開放原生 App）。**主動串聯**的做法是用 iOS「捷徑」讀取當日數值，組成 `key:value` 文字後，經 App 網址 `#hs=…` 或「從捷徑貼上」餵入；可搭配「自動化」設每天早上自動執行。文字格式：`weight:70.5; sbp:120; dbp:80; hr:62; glucose:95; date:2026-08-08`（分號／換行分隔，`date` 可省略，血壓也可寫 `bp:120/80`）。完整歷史則用 Apple 健康「匯出所有健康資料」上傳 zip。
>
> **關於健保：** 台灣全民健保基於資安設計，未開放第三方 App 直接讀取。正確流程是由本人到「健保快易通／健康存摺」匯出自己的資料後於此匯入。
>
> **匯入穩定性：** 匯入採**寬鬆 JSON 解析**，會自動去除健康存摺檔常見的 BOM、XSSI 前綴與字串內未跳脫的控制字元／換行、尾逗號（過去這些會讓嚴格 `JSON.parse` 直接失敗而被略過）。用藥與檢驗除 FHIR 外，也支援健保「醫療類」官方 **`myhealthbank.bdata`** 格式（檢驗值由 `r7` 依項目名稱對應、並以生理範圍剔除把費用誤判為數值的情形）。若檔案能讀取但無法辨識，「匯入串接」會顯示可安全分享的**檔案結構大綱**或**內容預覽**協助對格式。

## 🔥 Firebase 雲端同步（推薦，手機即可設定）

前端直接串接 Firebase（Firestore + Email/密碼登入），**免部署伺服器**，設定全程可在手機瀏覽器完成：

1. 到 [Firebase 主控台](https://console.firebase.google.com/) 建立專案。
2. 開啟 **Firestore Database**（地區建議 `asia-east1`）與 **Authentication → 電子郵件/密碼**。
3. 專案設定 → 新增 Web App → 複製整段 `firebaseConfig`。
4. 於 App「設定 → 🔥 Firebase 雲端同步」輸入 Email/密碼 → 註冊 → 登入即可（App 已內建預設 Firebase 設定；若要改用自己的專案，於「進階」貼上 config）。其他裝置用同帳密登入即同步。
5. 於 Firestore「規則」貼上（只允許本人讀寫自己的資料）：

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

> 健康資料存於 `users/{uid}/lifespan/data`，只有登入本人能讀寫。若專案已有 `match /users/{userId}/…` 規則（與其他 App 共用），通常無需更動。密碼僅用於登入，不會被上傳或儲存到雲端。

## ☁️ 雲端後台與自動化（進階，`health-backend.gs`）

以 Google Apps Script + 試算表作為個人健康資料的雲端中心：儲存、比對、跨裝置同步，並可自動化。**部署步驟需在電腦上完成（手機無法建立 Apps Script）**，額外提供每日/每週自動 Email 守護。

- `setupWeeklyTrigger()`：每週一早上 8 點自動產生健康週報並寄 Email。
- `setupDailyWatch()`：每日早上 9 點自動執行警示引擎，偵測到危險門檻或惡化趨勢才主動寄警告信（無警示則不打擾）。
- `setAiConfig('gemini','你的KEY')`：金鑰存於 Script Properties，設定後每日守護信與週報會附上 AI 個人化解讀。

設定：開啟 Google 試算表 → 擴充功能 → Apps Script → 貼上 `health-backend.gs` → 執行 `setup*` 函式授權 → 部署為網頁應用程式（執行身分：我；存取：所有人）→ 複製網址貼入 App「設定 → 雲端後台」→ 測試連線。

## 💾 備份、還原與匯出

到「⚙️ 設定 → 💾 備份與還原」：

| 方式 | 產生檔案 | 用途 | 能否還原 |
|---|---|---|---|
| 💾 **立即備份** | `lifespan-health-*.json` | 叫出手機「分享」→ 存到你自己的雲端硬碟（免登入、免設定） | ✅ 可還原 |
| 🔒 **加密備份** | `lifespan-health-*.enc.json` | 用**密碼上鎖**（AES-GCM 於裝置本機加密，密碼不上傳），適合放公用電腦／分享雲端 | ✅ 需密碼還原 |
| ♻️ **還原** | 選上述任一檔 | 換手機／清快取後把資料救回；加密檔會自動要求輸入密碼 | — |
| 📦 **匯出全部 CSV** | `lifespan-all-csv-*.zip` | 六類紀錄各一個 CSV 打包成 ZIP，方便丟 Excel 分析 | ❌ 僅供檢視 |

> 各紀錄頁（檢驗／用藥／手術／影像／病史／篩檢）也都有各自的「📤 匯出 CSV」。**換手機或想完整帶走請用 JSON 備份**；CSV 是給人／Excel 看的，不能還原。
